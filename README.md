# tampermonkey-github-last-comment

GitHub 이슈/PR 목록에서 **제목 다음 줄에 마지막 댓글 작성자 + 날짜·요일·오전/오후 시각**을 표시하는 Tampermonkey userscript. 배지에 마우스를 올리면 마지막 댓글을 **마크다운 서식으로 미리 볼 수 있어**.

## 설치 및 업데이트

1. Tampermonkey 설치 (Chrome / Edge / Firefox)
2. 아래 Raw 링크를 열고 Tampermonkey 설치/업데이트 화면에서 확인
   - https://raw.githubusercontent.com/eddy961206/tampermonkey-github-last-comment/main/github-last-comment.user.js
3. 설치된 스크립트의 `// @version`이 `1.7.0`인지 확인하고 GitHub 목록을 새로고침

`@updateURL` / `@downloadURL`이 설정되어 있어. 자동 업데이트 확인 시점은 Tampermonkey 설정에 따라 달라져. 저장소에 반영되는 것과 이미 열린 브라우저에서 새 버전이 실행되는 것은 별개야. Raw 링크로 업데이트하거나 기존 스크립트 내용을 교체한 뒤 목록을 새로고침해. 구버전과 신버전을 별도 스크립트로 동시에 켜두지 않아야 해.

v1.7은 원문 마크다운 변환용으로 `marked@18.0.7`을 버전 고정된 jsDelivr `@require` URL에서 가져와. 업데이트 시 이 의존성도 받을 수 있어야 해. 댓글 본문을 외부 마크다운 변환 서버로 보내지는 않아.

## 표시와 사용 방법

```text
이슈 제목
    마지막 댓글 : [ @developerA  9.4 (금) 오전 10:04  💬 ↻ ]
```

- 제목 다음 줄에 `2em`(현재 글꼴 크기에서 24px) 들여쓰기로 표시해. `마지막 댓글 :` 문구는 상자 밖에 있고, 상자는 내용에 맞는 너비를 사용해.
- 날짜와 시각은 한국 시간 `Asia/Seoul` 기준 **`M.D (요일) 오전/오후 H:MM`** 형식이야. 미리보기 머리글에는 `2026.9.4 (금) 오전 10:04 KST`처럼 연도도 표시해. 자정은 `오전 12:00`, 정오는 `오후 12:00`으로 나와.
- 배지에 마우스를 올리거나 작성자 링크에 키보드 포커스를 두면 본문 미리보기가 열려. 말풍선 버튼으로도 열 수 있어. 작성자 링크를 클릭하면 해당 댓글로 이동해.
- 미리보기 위로 마우스를 옮겨 내용을 읽거나 스크롤할 수 있어. `↓`로 본문에 포커스를 옮기고, `Esc` 또는 닫기 버튼으로 닫을 수 있어.
- `↻`는 해당 이슈를 다시 조회해. 기존 결과가 남아 있으면 점선과 `이전 결과`로 최신 확인 여부를 구분해.
- 좁은 화면에서는 작성자와 날짜를 상자 안에서 두 줄로 배치해. 요일이나 시각을 숨기지는 않아.

## 마크다운 미리보기

GitHub 응답에 서식 있는 `bodyHTML`이 있으면 우선 사용해. 원문 마크다운만 있으면 Marked로 변환해. `bodyText`처럼 이미 서식이 제거된 텍스트만 제공된 경우에는 서식을 추측하지 않고 텍스트로 표시해.

제목, 굵게/기울임/취소선, 목록, 읽기 전용 체크리스트, 표, 인용문, 인라인 코드와 코드블록, 링크, 접기/펼치기를 표시해. 넓은 표와 긴 코드 줄은 미리보기 안에서 스크롤할 수 있어. 수식·Mermaid·동영상 등 GitHub의 모든 특수 렌더링을 재현하는 기능은 아니야.

HTML은 원본 노드를 그대로 붙이지 않고 허용한 태그와 속성만 새로 만들어서 표시해. 스크립트, 이벤트 속성, 임의 스타일, 폼, iframe, SVG/MathML, 위험한 링크 등은 제외해. 링크는 새 탭으로 열고, 체크박스는 댓글을 수정하지 않는 읽기 전용이야.

GitHub 첨부 파일·이미지 호스팅·프록시의 허용된 HTTPS 이미지 주소는 표시하고, 다른 외부 이미지는 자동으로 불러오지 않고 링크로 보여줘. 이미지 접근 권한이나 만료된 주소 때문에 이미지를 받지 못하면 실패 안내가 나올 수 있어.

표시량은 최대 16,000 텍스트 문자 및 4,000개 노드로 제한해. 원본 HTML 크기·중첩 깊이에도 제한을 두며, 일부만 보여준 경우에는 `긴 댓글 일부만 표시` 안내가 나와. 서식 변환에 실패하면 실행 가능한 HTML을 넣는 대신 원문 텍스트와 실패 안내를 보여줘.

## 성능 및 저장 범위

기존 가시 영역 우선 조회, 증분 DOM 처리, 동시 요청 2개 제한을 유지해. 이미 받은 마지막 댓글 본문은 호버할 때 다시 요청하지 않아. 작성자·날짜 캐시만 있고 본문이 없는 경우에는 미리보기를 열 때 기존 조회 대기열로 본문을 가져와.

서식 변환은 미리보기를 열 때만 수행하고, 변환한 결과는 최근 8개까지 재사용해. 같은 본문을 열어둔 상태에서 조회 상태나 유효 시간 표시만 바뀌면 본문 DOM을 다시 만들지 않아. 이때 스크롤, 펼친 접기 영역과 텍스트 선택을 유지해. 실제로 새 본문을 받은 경우에는 새 내용으로 바뀌어.

본문 원본은 페이지 메모리에 최대 80개 보관해. 항목당 HTML 원본은 최대 128,000자, 원문 마크다운·일반 텍스트는 최대 16,000자로 제한해. 스크립트가 본문이나 렌더링 HTML을 sessionStorage/localStorage 또는 진단 로그에 저장하지는 않아. 화면 경로·계정이 바뀌면 본문과 렌더링 캐시를 비워. 작성자·날짜 등 결과 메타데이터는 기존처럼 탭별 sessionStorage에 저장하고, 표시 설정은 localStorage에 저장해.

## 적용 페이지 (v1.7)

- `https://github.com/*`에서 실행되지만 내부에서 이슈/PR 목록과 지원하는 검색 화면만 처리해. `@noframes`로 프레임에서는 실행하지 않아.
- 대상은 일반 댓글이야. 이슈 본문, 참조·커밋 이벤트, PR 코드줄 리뷰 댓글은 마지막 일반 댓글로 계산하지 않아.
- 로그인된 GitHub 세션과 GitHub 내부 페이지/조회 형식을 사용해. GitHub 구조가 바뀌면 수정이 필요할 수 있어. 확인하지 못한 결과는 댓글 없음으로 단정하지 않아.

## 로컬 개발 및 검증 범위

```powershell
# 클론 위치
# D:\WorkSpaces\js_workspace\tampermonkey-github-last-comment
node --check github-last-comment.user.js
```

파일을 고친 뒤 Tampermonkey에서 위 Raw URL로 업데이트하거나, 대시보드에서 해당 스크립트를 열고 붙여넣기로 동작을 확인해.

v1.7 개발 검증에서는 문법 검사와 Chromium/Playwright 기반 모의 검사 66개를 통과했어. 서식 있는 HTML 본문, 오전/오후 시각과 자정·정오, 호버·키보드·버튼 조작, 스크롤과 접기 상태 유지, 렌더링 캐시 제한, 위험한 HTML 입력 13종, 데스크톱/다크 테마/390px 화면을 검사했어.

검증 환경의 사이트 탐색 정책 때문에 실제 페이지 대신 `about:blank`에 모의 DOM을 넣고 주소·응답·저장소를 주입했어. Marked CDN 패키지를 실제로 받아 실행한 통합 검사는 하지 못했고, 원문 Markdown 변환 연결은 대역 함수로 검사했어. 실제 로그인한 GitHub + Tampermonkey + Refined GitHub 및 외부 의존성 로딩에 대한 실사용 검증과는 구분해야 해.
